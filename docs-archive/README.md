# docs-archive - superseded documentation staging

Holding area for documentation superseded by the 2026-08 reconstruction.
Nothing in here is a live reference: the current documentation lives in
docs/ (source) and the generated output in docs/_build/. Files land here
via `git mv` when a rewrite supersedes them, so history is preserved,
and the whole folder is destined for offsite storage. Do not link to
anything in this folder from live docs.
